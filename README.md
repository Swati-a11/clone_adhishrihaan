# Adhishrihaan Foundation Website

A homepage replica of the Adhishrihaan Foundation website, built using React and Bootstrap.

## Features
- Responsive navbar and dropdown menus
- Hero image slider with navigation
- Main content sections
- Smooth scroll animations
- Responsive design for different screen sizes

## Live Demo
https://clone-adhishrihaan.vercel.app/

## Tech Stack
- React.js
- Bootstrap 5
- CSS
- JavaScript

## Run Locally

```bash
npm install
npm run dev
```

Open the local URL shown in your terminal to view the website.

## Note
This project was created as a frontend development task to practice React, Bootstrap, and responsive web design.
